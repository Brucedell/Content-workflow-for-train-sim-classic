The Model Editor and the vehicle metadata

The Model Editor is TF3's Blueprint Editor and asset previewer in one. This part walks through importing the FBX set, filling every metadata struct a rail vehicle needs, validating, making icons, and the rail-specific extras: fake bogies, multiple units and buy-menu groups.

1 · Set up and first start

  1. Run ModelEditor.bat (Windows), ModelEditor.sh (Linux) or ModelEditor.command (macOS) from the game's installation folder. Two windows open: a console and the UI. manual
  2. On first start it writes a config file under %APPDATA%/Transport Fever 3/ (or ~/.local/share/Transport Fever 3, or ~/Library/Application Support/Transport Fever 3/) and asks for the userDataPath. Find it in game: Settings ▸ Advanced ▸ Open user data folder. Use forward slashes only. manual
  3. Restart. The open dialog now browses the base game and every mod in the staging area. manual
  4. Options ▸ Im-/Export: tick Use Blender Coordinate System; decide the Overwrite… switches (meshes/animations/materials/textures) for re-imports. manual
  5. Options ▸ Config: set Enable Auto Update to On Focus if your paint program writes textures slowly (black textures otherwise). manual

2 · Import: template first, then the FBX folder

  • Folder name decides the content path: vehicle-train-myloco/ → vehicle/train/myloco/myloco.mdl; use + instead of the last - to put several models in one folder (multiple units). manual
  • Drag a single FBX for one LOD, the folder for all LODs. manual
  • Bulk: drag a .txt with ModRefName;<modid> and Path;… lines to import many models. manual
  • After import, the Model window shows the node tree with mesh references and material/animation counts; hover a line to isolate the mesh; double-click a name to copy it for metadata. manual

4 · Compartments and seats

compartmentsList = {
  { loadConfigs = {
      { cargoEntry = { capacity = 80,
          cargoTypeSet = { cargoClassesIncluded = { "PASSENGERS" }, cargoClassesExcluded = {},
                           cargoTypesIncluded = {}, cargoTypesExcluded = {} },
          loadIndicator = "", seats = {} },
        toHide = {} },
  } },
},
  • One compartment is usually enough; several load configs when the same space can carry different cargo splits (coal only, or coal + ore). manual
  • A locomotive normally has an empty compartmentsList = {} and a crew seat; a coach has passenger capacity and passenger seats; a wagon has a cargo class and, for visible loads, a loadIndicator with a cargoBay on a node. manual
  • Seats: place |seat_sitting empties in Blender for passengers (the import brings them in), or add them in the editor with the Seat Locators render option on. manual

5 · Fake bogies

railVehicle = { config = { axles = { "w1", "w2" },
  fakeBogies = { { { group = "body", offset = 0, position = 4.0, upright = false } },   -- LOD 0
                 { { group = "body", offset = 0, position = 4.0, upright = false } } } } }  -- LOD 1

Validation fails if the list length differs from the LOD count (“size (= 2) must match number of lods (= 3) or be empty”). manual

6 · Validation

The top-bar validate button checks metadata and reports one issue at a time; run it again after each fix. manual Messages you will meet on a rail vehicle:

Referenced mesh node 'XYZ' not found (key: 'seatProvider.seats[10]')Seat group names a node that does not exist (renamed? LOD?).
transportVehicle/loadConfigs: list of load configs must not be emptyEvery compartment needs at least one load config.

7 · Icons and screenshots

Press SCREENSHOT: it generates the three UI icons (_store, _small_icon, _icon20) and moves them into the mod, plus orthographic and perspective renders in screenshots/ under the user data path. The game needs .tga. Options ▸ Icons sets the stage track model, sizes, pixels per metre and which outputs to generate; Bulk Generate does a whole folder. manual

8 · Multiple units and buy-menu groups

-- myunit.mu.lua, next to the .mdl files
function data() return {
  vehicles = {
    { name = "myloco.mdl",   forward = true },
    { name = "mycoach.mdl",  forward = true },
    { name = "myloco.mdl",   forward = false },  -- flipped 180°
  },
  name = _("VEHICLE_MU_MYUNIT_NAME"),
  desc = _("VEHICLE_MU_MYUNIT_DESCRIPTION"),
  filterTags = { "default" },
  groupFileName = "",
} end

All parts must be within their availability years for the unit to appear. manual

Groups

Set transportVehicle.groupFileName = "menu_myloco.mdl" (relative path) on each variant to group liveries or lengths under one store entry. For a custom group icon, make a placeholder model with multipleUnitOnly = true and no groupFileName; it is never sold, only shown as the parent. Icon style: up to four variants, 30 px apart, ≤ 327 px wide. manual

9 · Repaints: the cheap second livery

A repaint mod changes only textures: new .mtl per re-textured material (map_albedo_opacity, map_normal, map_metal_gloss_ao, map_cblend_dirt_rust), a new .mdl per variant whose material references point at them in every LOD, new UI icons, new textures, a different modId and the original mod as dependency. manual This is how your TSC liveries become TF3 variants without touching the meshes.
